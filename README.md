## 🎯 Project Overview

**StudenKZ** is an innovative digital super-platform designed specifically for university students in Kazakhstan. It combines essential student services into a single, seamless mobile application.

### Target Audience
- 500,000+ university students across Kazakhstan
- Age: 17-25 years old
- Tech-savvy Gen Z demographic
- Budget-conscious, socially active lifestyle

### Vision
Create a unified ecosystem where Kazakhstan's students can:
- 📖 Buy and sell textbooks
- 🍔 Order food from campus restaurants  
- 👥 Join clubs and find events
- 🎓 Connect with tutors and roommates
- 💳 Manage finances with digital wallet
- 🎁 Access exclusive student discounts

---

## ✨ Features

### 📖 Marketplace
- Buy, sell, and exchange textbooks and study materials
- Condition tracking and photo verification
- University and year-specific filtering
- Secure escrow transactions
- In-app messaging with sellers

### 🍔 Food Delivery
- Order from campus restaurants and cafes
- Real-time order tracking with live map
- Customizable menu items
- Student-friendly portions and pricing
- Group ordering with automatic bill splitting

### 👥 Community
- Discover and join student clubs
- Create and attend events
- Club chat and discussions
- Photo galleries and updates
- RSVP and attendance tracking

### 🎓 Tutors & Roommates
- Find peer tutors by subject
- Book tutoring sessions
- Search for roommates with matching preferences
- Rating and review system
- In-app scheduling and payments

### 💳 FinTech Services
- Digital student wallet
- Peer-to-peer money transfers
- 3-5% cashback on all purchases
- Transaction history and analytics
- University payment integration

### 👤 Profile & Gamification
- Student verification badges
- Achievement system and loyalty levels
- Referral program (1,000₸ per friend)
- Activity tracking and statistics
- Personalized recommendations

## 🎨 Design Highlights

### Color Palette
- **Primary:** `#1FB8CD` (Bright Cyan) — Main accent and CTAs
- **Secondary:** `#13343B` (Dark Teal) — Text and contrasts  
- **Success:** `#34D399` (Green) — Confirmations and positive actions
- **Background:** `#FCFCF9` (Cream White) — Main background

### Typography
- **Primary Font:** FK Grotesk Neue
- **Fallbacks:** Inter, SF Pro Display, Montserrat
- **Mobile-first** with responsive scaling

### Design Principles
1. **Modern & Youthful** — Contemporary design for Gen Z
2. **Clean & Functional** — Usability over decoration
3. **Fast & Responsive** — 60 FPS animations, instant feedback
4. **Accessible & Inclusive** — WCAG AA compliance

## 🛠️ Tech Stack

### Mobile App (Recommended)
- **Framework:** React Native with Expo
- **State Management:** Zustand + React Query
- **Navigation:** React Navigation
- **Styling:** Styled Components / Tailwind
- **Maps:** Google Maps API
- **Push Notifications:** Firebase Cloud Messaging

### Backend (Recommended)
- **Framework:** Node.js + Express or NestJS
- **Database:** PostgreSQL + Redis
- **Storage:** AWS S3 or Cloudflare R2
- **Authentication:** JWT + Firebase Auth
- **Payments:** Kaspi, Wooppay

See [Developer Handoff](./docs/DEVELOPER_HANDOFF.md) for complete technical specifications.
